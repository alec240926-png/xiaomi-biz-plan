三条原则
轻资产（无硬件、无销售团队、近零固定成本）· 动结构，不加时间（涨价、1 对多、产品化，而非多上课）· 每周 10 小时红线（内容 + 商单线的人力上限，超了就砍渠道）

一、长期规划：VIP 俱乐部

1.1 形态定义

上限 20–30 人的高端滑雪俱乐部，近零固定成本，阶梯产品：

入门测评/体验课（钩子） → 年度 VIP 会员（3 万起，课次有闸，含 AI 复盘/年度计划） → 核心 VIP（1–2 个名额，陪赛陪滑，价格随行就市）
  • waitlist 常态化：排队也给糖（免费公开课、AI 诊断体验），排队本身是营销资产
  • 松花湖短训营对外招生 = 俱乐部漏斗上层，营员筛会员

1.2 五年发展曲线

阶段规模关键动作
第 1 年12–15 人涨价过渡（老会员老价）、课次加闸、服务仪式化（年度评估报告、等级徽章）
第 2–3 年20 人封顶waitlist 运营、助教 1–2 人（兼职教练，你培训+抽成）、松花湖营 2 期/年
第 4–5 年20 人 + 助教交付教学法成册，"教教练"模块启动
第 5 年+品牌 > 个人俱乐部成为滑雪教学领域的品牌；时间在教学中的占比持续下降

1.3 年度商业节奏（上海 9 个月 + 松花湖 3 个月）

时段地点业务角色
9–12 月上海室内招新季 + 基础高频训练（现金流基本盘）
12–3 月松花湖实战交付 + 短训营 + 比赛 + 内容高峰
3–6 月回上海复盘续费 + 工具迭代 + 老会员深度服务
  • 外地/南方学员：无法常驻上海 → 远程 AI 诊断 + 松花湖短训营组合
  • 内容蓝海：市面滑雪内容 90% 是户外大山，"城市室内雪场练刻滑"差异化显著

1.4 两个系统性风险（提前埋解法）

风险解法

二、中短期方案：视频内容 + 商单

2.1 总策略

一个 IP，全网分发，一鱼多吃。不做矩阵号——VIP 俱乐部品牌需要一个强人设。

📋 配套执行手册
六个平台逐个拆解（人群画像 / 盈利方式 / 时间分配）+ 六 Agent 内容生产系统设计：打开《内容制作执行手册》 →

2.2 渠道矩阵（国内 + 海外）

渠道角色形态/频率
小红书高客单转化主阵地（付费能力强、搜索心智）图文+短视频，日更
抖音流量 + 直播主阵地竖屏短视频，日更；每周 1 次直播
视频号私域联动、中年高净值同步分发 + 直播
B 站深度技术、程序员/科技人群横屏长视频，周更 1 条（可砍）
YouTube海外主阵地：中文盘 + 英文盘双轨长视频 + Shorts，周更
TikTok / IG Reels海外短视频分发竖屏同步
Facebook / Reddit海外华人社群渗透（轻运营）分发 + 社群互动
快手 / 知乎 / 微博占位即可同步/搜索

海外优先级：Tier 1（第 6 个月）中文内容出海（海外华人 + 赴日滑雪人群，零成本复用）→ Tier 2（第 9–12 个月）英语（AI 配音，刻滑教学在 YouTube 是大赛道）→ Tier 3（远期）日语/赴日中文教学盘，暂挂起。

2.3 内容类型（五条产品线）

类型占比生产方式作用
A. 纠错对比（一节课改一个动作，AI 姿态标注前后对比）核心实拍 + AI 后期差异化命门："AI 工具 + 省冠眼光"
B. 口播干货批量录制（答疑库生产化）~50%真人出镜 + 提词器，一次拍 5–7 条铺量、占搜索、省时间
C. 人设信任（比赛 vlog、松花湖驻扎、学员进步纪录）~30%实拍高客单信任来源，全账号的压舱石
D. 装备测评≤15%实拍+口播混商单载体
E. AI 工具叙事（"我让 AI 学会刻滑"系列）少量精品录屏+实拍破圈钩子，科技人群入口

周更结构：批量口播 4–5 条 + 实拍 2 条 + 长视频 1 条。"AI 辅助的冠军教练" 本身即传播钩子。

2.4 生产方式（AI 流水线，人只做出镜和终审）

知识库 + LLM 起草脚本 → 提词器批量口播 / 实拍 → 自动剪辑/字幕/包装 → 多语言（英文字幕/配音）→ 多尺寸重构（16:9 / 9:16 / 1:1）→ 定时全平台分发
  • 个人只做：选题终审（每周 1 h）、批量出镜（每周 1.5–2 h，提词器一次拍完一周的量）
  • 私域承接：自动欢迎语 + 钩子资料 + AI 助手答疑，大幅压缩回消息时间
  • 口播内容只讲独家（冠军视角、学员案例、解读库），不讲通用科普 —— 防同质化

2.6 商单业务升级路径

装备置换（现状 ~1 万/年） → 单条付费（测评/植入/口播，效果分佣+一口价双轨） → 年框大使（比赛曝光 + 雪服雪板露出 + 内容年框，2–3 个品牌）
  • Media kit 是谈判开关：全平台粉丝/播放中位数/粉丝画像（滑雪人群 = 汽车、3C、金融的高价值人群；程序员受众对数码商单尤其值钱）/历史转化案例
  • 品类优先级：雪具 → 雪场/室内雪场（联合课程）→ 汽车/3C（客单天花板最高）→ 运动消费
  • 纪律：商单占比 ≤15%；不接与"高端教学"定位冲突的品牌

四、生存红线与执行节奏

4.1 三条生存红线

红线 1 · 渠道
月加微连续两个月 < 30 → 停 B 站、视频号只同步不运营，all-in 小红书 + 抖音。渠道贪多是 10 小时模式的头号死因。
红线 2 · 承接
承接时间被挤压 < 3 h/周 → 减内容产量（口播降到 3–4 条）。不加承接 = leads 烂在手里，前面流量全白费。宁可少发内容，不可烂接 lead。
红线 3 · 商单
商单洽谈 > 5 h/月 → 推掉或延后。第 1 年商单是顺带的，不值动会员成交时间。

4.2 季节节奏

上海 9 个月攒内容、做承接；松花湖 3 个月吃存量、做转化。雪季前去一次拍够 3 个月素材库存，营期发库存 + 提前录好的口播。

4.3 风险清单

风险应对
真人口播产能瓶颈/内容同质化提词器批量录制保供片；只讲独家内容，不讲通用科普
多平台精力被榨干分发自动化，绝不人工逐平台运营
涨价流失老会员老价、新会员新价过渡

附录 ·机会挖掘方法论（速查）

底层公式：机会 = 错配

错配类型含义滑雪领域例
需求缺口有人要，没人好好给进阶者想练刻滑，雪场只有初级团课
信息缺口有好东西，没人知道水平超出当地名气
空间错配供给和需求不在同一地方南方的钱 vs 北方的雪
时间错配供给和需求不在同一时间雪季爆满 vs 夏天闲置

六维扫描法

  1. 从客群出发：切片三问——痛点是什么？现在找谁解决？现在的供给烂在哪？
  2. 从场景出发：流程（学前/学中/学后/不学的日子）× 空间（雪上/大厅/城市/线上），逐格问"这一刻谁难受？"
  3. 从地域出发：钱和雪错位的地方就是生意
  4. 从产业链出发：沿钱流走——装备/教学/内容/赛事/旅行，哪个环节利润厚、离能力近？
  5. 从技术出发：问"什么成本趋零"——AI 让动作分析、个性化计划、内容产能趋零，新品类由此诞生
  6. 从事件出发：开板季、节假日、赛事节点——机会藏在日历里

交集法

画两个圈取交集，交集处长出新品类（滑雪 × 编程 = 滑雪黑客松；滑雪 × 亲子 = 家庭营）。交集价值 ≈ 两圈规模 × 重合稀有度。最高级的一招：其中一个圈就是你自己（"省冠教练 ∩ AI builder"）。

筛选漏斗（五问）

  1. 已验证付费？（没人付过钱的东西先默认不存在）
  2. 复用现有资产？（客户、名气、内容、工具）
  3. 边际时间成本？（你的瓶颈是时间）
  4. 天花板？（能否脱离个人时间复制）
  5. 两周能 MVP 吗？（验证不了的点子是幻觉）

第一部分平台逐个拆解

平台规则（粉丝门槛、分成比例、商单入驻条件）变动频繁，以下以量级描述，动手前以各平台后台当期显示为准。

两个前提
① 所有"预期收入"的主体都是引流到私域后的成交（会员 3 万 / 营 5–8k），平台分成是零头；② 内容线 6 小时之外的 4 小时是成交承接，两条线不可互相挪用。

1. 小红书 —— 转化主阵地，优先级最高

1 h/周第 1 年 5–8 万

  • 人群画像：一二线女性为主（约七成），20–35 岁，消费决策前必搜，生活方式社区心智
  • 做什么：图文（教学干货清单、装备对比、学员前后对比）每周 3–4 篇；60 秒内短视频（纠错对比类）同步发；评论区和私信是主战场，爆款评论必回
  • 特点：长尾搜索流量占大头，一条爆款能吃一年；封面+标题决定 80% 点击
  • 盈利方式：蒲公英平台商单（约千粉可入驻，报价随粉丝量上浮）；买手合作挂链拿佣金；直播带货；平台没有播放分成
  • 一年预期：加微 ~190 人，引流成交 5–8 万；蒲公英商单 0–2 单（下半年起）

2. 抖音 —— 流量池 + 直播转化场

1 h/周（含直播摊薄）第 1 年 3–6 万

  • 人群画像：全年龄全地域，男性偏多，娱乐消费属性，完播率逻辑
  • 做什么：竖屏短视频日更（流水线供片）；每两周 1 次直播（雪季加密：学员答疑 + 装备 + 营期预告），直播是抖音唯一的高转化场景
  • 特点：公域推荐全国最强，但粉丝不值钱、流量值钱；单条爆款带来瞬时加微洪峰——会直接冲击承接红线，提前备好自动回复
  • 盈利方式：星图商单（入驻有粉丝门槛，以星图后台为准）；商品橱窗 CPS（需粉丝门槛+小额保证金）；播放分成类计划规则变动频繁，不纳入预期；直播打赏/带货
  • 一年预期：加微 ~145 人，成交 3–6 万；橱窗顺挂雪具链接，佣金当零花

3. 视频号 —— 私域的延伸，不花心思

0.2 h/周第 1 年 0–3 万

  • 人群画像：30–50 岁，中年高净值，微信生态内被动消费内容
  • 做什么：只同步分发，不做原创；年底看数据决定是否加直播
  • 特点：算法弱、社交强，适合"老会员转发到朋友圈"场景
  • 盈利方式：创作分成（邀请制，随缘）；直播打赏/带货（潜力项）
  • 一年预期：0–1 个高客单，纯捡漏

4. B 站 —— 当年不赚钱，两个战略价值

0.5 h/周第 1 年 ≈0（资产型）

  • 人群画像：18–30 岁男性为主，学生 + 程序员 + 技术宅浓度全平台最高——黑客松种子用户和 AI 工具叙事的受众就在这里
  • 做什么：每周 1 条 5–10 分钟横屏长视频（刻滑力学解析 / AI 动作分析工具 demo / 教学体系连载），弹幕互动
  • 特点：搜索长尾最强，三年前视频还在带流量；粉丝粘性最高，商单质量高（科技品牌偏爱 B 站）
  • 盈利方式：创作激励（门槛不高、收益微薄）；花火商单（有粉丝门槛）；充电/课堂
  • 一年预期：≈0，资产型投入；第 2 年起商单和工具种子用户在这里回收

5. YouTube —— 海外主阵地，第 6 个月启动

0.3 h/周第 1 年 0.5–1 万

  • 人群画像：中文盘 = 海外华人 + 留学生（付费能力最强的一群）；英文盘 = 全球刻滑爱好者（YouTube 上 carving 教学是大赛道）
  • 做什么：中文盘复用国内内容零成本；英文盘用 AI 配音+字幕（声音克隆或母语级 TTS），每周 1 条长视频 + Shorts 同步
  • 特点：内容寿命最长（一条视频吃三年）；搜索+推荐双引擎
  • 盈利方式：YPP 广告分成（公开门槛：1000 订阅 + 4000 小时观看，或 90 天内 1000 万 Shorts 播放，以官方为准；滑雪户外类 RPM 量级为每千次播放 1–5 美元，以实际为准）；联盟营销
  • 一年预期：松花湖营海外华人订单 0.5–1 万；广告分成 ≈0

6. TikTok / Instagram / Facebook —— 纯播种

0.2 h/周第 1 年 ≈0

  • 做什么：竖屏内容一键同步，不运营；Facebook 加 2–3 个海外华人滑雪群，每周冒泡一次
  • 盈利方式：TikTok Creator Rewards（万粉+播放门槛，且分地区，前期够不到）；IG/FB 无直接分成，靠品牌合作远期变现
  • 一年预期：≈0；第 2 年英文盘跑通后回收

第二部分平台收入模式全景与利益最大化运营

门槛和抽成比例为量级参考，各平台规则调整频繁，开通前以创作者后台当期显示为准。

抖音短视频本身没有播放分成——原生收入 = 挂车佣金 + 直播 + 商单 + 活动。利益最大化的核心指标不是播放量，是挂车率（每条能挂的视频都挂上）和直播频率。

约千粉就是商单起跑线——前期唯一目标是快速过千粉（蒲公英入驻 + 买手开通一次解锁）。没有播放分成，收入全部来自"商单 + 带货"，内容策略直接倒推：每篇笔记要么能挂链，要么能圈粉。

模式机制门槛适配度

原生收入都挂在直播上——分成计划是被动等，直播是主动做。真正的价值是"老会员转发朋友圈"带来的免费精准流量，变现动作放在年底测试直播。

5. YouTube —— 分成机制最成熟，英文盘才是金矿

8. 利益最大化运营方式（分渠道打法）

抖音：把"每条内容"都变成货架

  1. 基建先行：橱窗 + 团购达人一次性开通，雪具精选联盟 + 松花湖/上海雪场门票团购全部挂上——之后每发一条视频，挂车决策只要 10 秒
  2. 挂车率作为内容指标：纠错对比类挂"练习装备"，vlog 类挂"雪场团购"，装备类挂对应商品——不挂车的爆款等于白爆
  3. 直播常态化：每两周 1 次起步，内容 = 答疑（展示专业度）+ 装备展示 + 营期预告；直播同时吃打赏、带货、涨粉三份收益
  4. 蹭活动：每月创作者中心的活动赛必报——现金奖是顺手的，流量券更值钱
  5. 星图万粉后再认真经营；前期品牌私信可直接谈，大单子建议走平台有保障

小红书：冲千粉 → 全开挂 → 商单滚动

  1. 前 60 天唯一 KPI：千粉（解锁蒲公英 + 买手）。打法：干货图文覆盖滑雪人群搜索词 + 爆款评论互动
  2. 千粉当天三件事一次做完：蒲公英入驻、买手开通、好物体验站申请
  3. 此后每篇笔记三问：能挂链吗？能进搜索吗？能攒商单案例吗？——三样都不沾的选题不做
  4. 商单报价滚动上调：每接 2–3 单上调一次，用 media kit 数据支撑
  5. 好物体验持续申——装备白嫖 + 免费商单素材

视频号：等分成邀请，测年底直播

  1. 日常只同步，但每条视频结尾引导"转发给滑雪的朋友"——社交裂变是视频号的算法加权项
  2. 收到创作分成邀请即开（评论区广告自动有收入）
  3. 年底（雪季）测 2–3 场直播：客群是高净值中年人，卖高客单（营期、装备）而不是卖便宜货

B 站：课程上架 + 花火预备

  1. 万粉前：只做长视频连载（刻滑体系），攒电磁力拿激励
  2. 万粉前完成课程录制：系列课直接上架 B 站课堂——全平台"内容→课程"路径最顺的一个
  3. 万粉后：花火开入驻，科技品牌（相机、运动装备、AI 工具）商单重点经营
  4. 弹幕和评论重度互动——B 站粉丝的转化靠"UP 主人格"养出来

YouTube：Shorts 拉订阅，长视频吃三份钱

  1. 一条视频三层收益结构：YPP 分成 + 描述区联盟链接 + 结尾引导频道会员
  2. 英文盘内容策略：刻滑技术解析（搜索流量，长尾）+ AI 滑雪工具（差异化，科技圈传播）
  3. 千订阅前不指望分成，但联盟链接从第一天就挂（Amazon 联盟等无粉丝门槛）
  4. 每条视频描述模板固定化：时间戳 + 装备清单（全联盟链）+ 订阅引导

9. 通用规律：粉丝量级解锁地图

粉丝量级解锁什么
~500公众号流量主、视频号部分功能
~1000蒲公英、抖音橱窗、团购达人、YouTube YPP（订阅维度）、买手合作
~1 万星图档、花火、FB 广告分成、TikTok Rewards（若地区可行）
利益最大化总公式
每个渠道 = 主模式（深耕）+ 挂链/挂车（基建，零成本被动）+ 活动（顺手）。挂链挂车开通只要一次，收益跟每条内容走——这是所有平台里最被低估的动作。

第三部分Agent 系统设计方案

0. 总体架构：一个中台 + 六个 Agent

内容中台（飞书多维表格：选题库 / 知识库 / 素材库 / 数据看板）
→ ① 雷达 → ② 编剧 → ③ 制片 → ④ 投放 → ⑤ 营收 → ⑥ 私域
总原则
每个 Agent 的上线标准 = 每周至少省你 2 小时，达不到就回炉，不搞技术的自我感动。

① 雷达 Agent —— 每天早上的《选题雷达》

  • 数据源：①平台热榜（抖音/小红书热搜；轻量方案 = 人工扫一眼喂给 LLM，不为上爬虫冒封号风险）；②10 个对标账号监控（更新即抓取标题+数据）；③搜索趋势（微信指数/百度指数/Google Trends，周度）；④赛事日历 + 开板节点（手工维护一张表）
  • 输出：每天早上 8 点推送 5–10 条选题，每条附：热度证据 / 切入角度 / 适配渠道 / 预估制作成本
  • 人工介入：勾选 3–5 条进选题库，30 秒
  • 上线顺序：第 3 周（前期知识库就够选题吃）

② 编剧 Agent —— 一鱼多吃的脚本工厂

  • 输入：勾选的选题 + 知识库 RAG（历史答疑记录、教学文档、比赛素材描述——先花一个下午灌进去，一次性资产）
  • 输出：按渠道模板生成——抖音 60s（前 3 秒钩子三选一：错误示范/反常识断言/结果前置，口播稿+字幕文件+标签）；小红书（封面标题 10 选 1 + 正文 + 话题标签库自动匹配）；B 站（分镜大纲 + 口播稿，照着念+补画面）；YouTube 英文版（AI 翻译 + 母语化改写，非直译）
  • 人工介入：每周两次、每次 15 分钟终审——只改三处：事实、立场、钩子
  • 上线顺序：第 1 周，最先做（直接砍掉现在写脚本的时间）

③ 制片 Agent —— 你拍+配，数字人来建

  • 数字人设计：形象用你的视频做数字克隆（不是 3D 卡通人——"冠军教练的 AI 分身"人设必须与你本人一致，否则信任断裂）；声音克隆做 TTS，B 类内容完全无人化；口型驱动先用成熟 API 跑通，跑稳后再自研降本
  • 分工表：B 类（数字人知识）全自动：脚本→TTS→数字人→包装→成片，你只看一眼；A 类（纠错对比）：你雪场拍 3–5 条素材丢进文件夹 → AI 自动剪（粗剪→Whisper 字幕→错误标注叠加→前后对比包装）→ 你审；C 类（人设信任）：你拍 vlog 素材，AI 按模板出片；D 类（装备测评）：口播你录，画面 AI 补（B-roll 素材库自动匹配）
  • 素材流水线：手机拍 → 自动同步素材库（按"日期-场景-学员编号"归档，后期秒剪的前提）→ 成片回传内容中台待审
  • 人工介入：每周拍摄 1.5 h（一次拍完全部）+ 终审 0.5 h
  • 上线顺序：第 1–2 周，与编剧 Agent 构成"产能双核"

④ 投放 Agent —— 发布、回收、告警

  • 发布：半自动——按渠道排好发布时间，生成标题/标签/封面 A/B 两版，你一键确认（平台 API 限制 + 防封号，不做全自动发布）
  • 数据回收：每周自动生成周报：分渠道播放/完播/互动/涨粉/加微数（各平台钩子资料放不同渠道码做归因）；平台数据优先官方后台导出+导入，爬虫只做补充且有分寸
  • 红线监控：月加微连续两周 <30 自动告警（触发砍渠道动作）；承接响应时长 >5 分钟告警
  • 人工介入：每周看 10 分钟周报
  • 上线顺序：第 3–4 周

⑤ 营收 Agent —— 预期差距的深度解析（每月一次）

漏斗五层对标：实际 vs 预期，逐层定位问题——

层预期值低于预期时的诊断方向
曝光 → 加微月 40 人内容供给量够吗？爆款率？钩子资料领取率？→ 问题在内容或钩子
加微 → 响应<5 分钟自动欢迎失效？AI 分身答非所问率？→ 问题在私域 Agent
响应 → 体验35%钩子吸引力衰减？体验课门槛太高？→ 问题在钩子设计
体验 → 成交4%体验课质量？报价时机？信任不足？→ 问题在交付和话术
成交结构会员 : 营 : 商单商单占比超 15% 告警；会员续费率下滑提前预警
  • 输出：月度复盘报告 = 漏斗图 + 差距归因（定位到哪一层）+ 三个可执行的修正建议 + 下月假设更新（反馈到财务推演表的参数）
  • 关键设计：Agent 只负责定位和提建议，决策永远是你——防止系统用漂亮的图表把你带进过度优化

⑥ 私域承接 Agent —— 已在主计划书规划

自动欢迎语 + 钩子资料分发 + AI 分身答疑，本次不展开。
